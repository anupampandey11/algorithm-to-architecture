How hashing works

We use the hash function:

index = key % 7

The result tells us which bucket should contain the key.

Current operation

Enter a number and press Insert.

What you should notice

1. Take a key.
2. Apply the hash function.
3. Jump directly to that bucket.
4. If another key is already there, we have a collision.
5. Chaining lets multiple values live in the same bucket.
